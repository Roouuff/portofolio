# Portfolio Muhammad Abdul Rouf 🎨

Portfolio website pribadi yang menampilkan profil, keahlian, project, dan informasi kontak.

## 📋 Deskripsi

Website portfolio modern dengan desain colorful dan interaktif yang dibuat menggunakan HTML dan CSS. Portfolio ini menampilkan informasi tentang saya sebagai mahasiswa Teknik Informatika di Universitas Hasyim Asy'ari Tebuireng.

## ✨ Fitur

- **Responsive Design** - Tampilan optimal di berbagai ukuran layar
- **Smooth Animations** - Animasi halus untuk pengalaman pengguna yang lebih baik
- **Gradient Backgrounds** - Desain modern dengan gradient yang menarik
- **Sticky Navigation** - Menu navigasi yang tetap terlihat saat scroll
- **Interactive Cards** - Kartu skill dan project dengan hover effects
- **Contact Links** - Link langsung ke email, LinkedIn, Instagram, dan GitHub

## 🛠️ Teknologi yang Digunakan

- HTML5
- CSS3
- Google Fonts (Segoe UI)

## 📁 Struktur File

```
portofolio/
│
├── index.html          # File HTML utama
├── css/
│   └── style.css       # File CSS untuk styling
├── img/
│   └── Animation.jpg   # Foto profil
└── README.md          # Dokumentasi project
```

## 🚀 Cara Menjalankan

1. Clone atau download repository ini
2. Pastikan struktur folder sesuai (css/, img/)
3. Buka file `index.html` di browser favorit Anda

## 🎨 Customization

Untuk mengkustomisasi website:

1. **Warna**: Edit gradient colors di `style.css`
2. **Font**: Ganti font family di bagian `body` CSS
3. **Konten**: Update informasi di `index.html`
4. **Foto**: Ganti file `Animation.jpg` dengan foto Anda

## 📝 Catatan Penting

- Beberapa emoji mungkin tidak tampil dengan baik di semua browser
- Link LinkedIn perlu diupdate dengan username yang sesuai

## 🔧 Perbaikan yang Disarankan

1. Update link LinkedIn dengan username yang benar
2. Tambahkan meta description untuk SEO
3. Tambahkan favicon
4. Update path gambar di HTML dari `Animation.jpg` menjadi `img/Animation.jpg`
